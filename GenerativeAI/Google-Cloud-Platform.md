# Google Cloud Platform
---

- Cloud computing is use of softwares and hardwares to deliver a service to a network. Users can access these files and applications from any device that can access internet. Cloud computing is the delivery of computing services such as servers, storage, databases, networking, and software over the internet instead of using local computers. It allows users to access resources on demand without owning or maintaining physical hardware. Cloud services are scalable, cost-effective, and can be accessed from anywhere with an internet connection. Businesses use cloud computing to improve flexibility, reduce infrastructure costs, and deploy applications quickly.

- models offered by different cloud providers are as follows - 
    - Infrastructure as a Service (IaaS): Provides virtual servers, storage, networking, and other computing resources over the internet.
    - Platform as a Service (PaaS): Offers a platform for developers to build, test, and deploy applications without managing the underlying infrastructure.
    - Software as a Service (SaaS): Delivers software applications over the internet, allowing users to access them through a web browser without installation.

- Why google cloud platform - 
    - Powered by Google's Infrastructure – Uses the same global infrastructure that runs Google services like Search Gmail, and YouTube.
    - Fast Global Network – Google's private fiber network provides low latency and high-speed connectivity worldwide.
    - Pay-as-You-Go Pricing – Pay only for the resources you use, with no upfront investment.
    - Automatic Scaling – Resources can automatically scale up or down based on application demand.
    - Strong Security – Built-in security features such as encryption, Identity and Access Management (IAM), firewalls, and DDoS protection.
    - High Availability and Reliability – Multiple regions and zones ensure applications remain available even if one location fails.
    - Best for Data Analytics – Services like BigQuery enable fast analysis of large datasets without managing infrastructure.
    - AI and Machine Learning Services – Provides tools like Vertex AI to build, train, and deploy machine learning models.
    - Container and Kubernetes Support – Google Kubernetes Engine (GKE) makes it easy to deploy and manage containerized applications.
    - Serverless Computing – Services like Cloud Run and Cloud Functions let you run code without managing servers.
    - Developer-Friendly – Supports popular programming languages, APIs, and DevOps tools for faster application development.
    - Sustainability – Google Cloud is designed to be energy-efficient and aims to operate using carbon-free energy.
    - Pricing is based on monthly usage.
